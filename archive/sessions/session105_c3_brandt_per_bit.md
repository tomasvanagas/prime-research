# Session 105 — C3 BUILT: Brandt obstructions × per-bit difficulty

**Mode.** CONSTRUCTION (NOVELTY_CHALLENGES §1).
**Target.** C3 — compose E5.8 (Brandt-class barrier) with E1.3
(per-bit difficulty profile).
**Self-grade.** **B**.

## What was built

A new mathematical object: the per-bit prime-counting function

```
    π_J : ℕ → {0,1},     π_J(x) := bit J of π(x)  (J=0 is LSB)
```

and the per-bit family

```
    F_N := { s_J^(N) := ( π_J(0), ..., π_J(2^N - 1) ) : J = 0..N-1 }.
```

Under the bounded-Kt simulator from `brandt_mktp/` (3-bit-per-op
stack VM, L_MAX = 12, T_MAX = 4096, INF = 61), computed
`Kt_b(s_J^(N))` for N ∈ {3..7}, J ∈ [0, N-1].

End-to-end runtime: 0.44 s.

## Pre-stated falsifiers vs outcome

Three outcomes pre-registered in `definition.md` and
`brandt_per_bit_results.md` (the latter written before run output
was filled in):

| Falsifier | Predicted reading | Outcome |
|-----------|-------------------|---------|
| F1 (uniform saturation) | per-bit decomposition gives no new structure → DUPLICATE-PLUS of E5.8 | Refuted (saturation is J-stratified) |
| F2 (J-stratified at E1.3's 0.5N cut) | bounded VM distinguishes E1.3's hard / easy halves at the same boundary | Holds in saturation regime N ≥ 4 — but cut location is materially higher than 0.5N |
| F3 (anomalous) | non-monotonic or off-cut → potentially new edge | Did not occur as pure anomaly |

**Selected outcome: F2-strict-but-sharpened.** The bounded-Kt cut
location is at **J*(N) := ⌈log₂( π(2^N - 1) + 1 )⌉ ≈ N − log₂ N**,
not at E1.3's 0.5N. Numerical comparison:

| N | π(2^N-1) | J*(N) | E1.3 cut (0.5N) | Gap |
|---|----------|-------|-----------------|-----|
| 4 | 6 | 3 | 2 | +1 |
| 5 | 11 | 4 | 2.5 | +1.5 |
| 6 | 18 | 5 | 3 | +2 |
| 7 | 31 | 5 | 3.5 | +1.5 |

For J ≥ J*(N), `π_J ≡ 0` and `Kt_b ∈ {5..8}` (program: `RPT4`,
3 bits, ≤ 4 steps). For J < J*(N) — including bits in E1.3's "easy
zone" J ∈ [⌈0.5N⌉, J*(N)) where Fourier weight at degree ≤ 2 is
high and R-correlation is ≥ 0.5 — `Kt_b = 61` (saturated).

Concrete easy-zone-saturating examples:

- N = 5, J = 3: 13 ones / 32 bits, Kt_b = 61 (E1.3 says easy)
- N = 6, J = 3: 34 ones / 64 bits, Kt_b = 61 (E1.3 says easy)
- N = 6, J = 4: 11 ones / 64 bits, Kt_b = 61 (E1.3 says easy)
- N = 7, J = 4: 75 ones / 128 bits, Kt_b = 61 (E1.3 says easy)

The bounded VM is **blind** to the smooth/oscillatory transition E1.3
detects via Fourier weight: it only resolves the *trivially-zero*
boundary at `J ≥ J*(N)`.

## Structural extension (independent of empirics)

Working through Brandt's four obstructions O1-O4 on the per-bit
family `{π_J : J = 0..N-1}`:

- **(O1)** Each `π_J` is a fixed total Boolean function. Parameter-
  control of J means the *family* depends on J, but each individual
  `π_J` is fixed. Brandt's TRAVERSE needs a hard string generated
  by oracle access during the run, not a fixed function. **O1 still
  applies to every J.**
- **(O2)** A `π_J`-decider answers "is bit J of π(x) set?", not
  "is z complicated?". No self-referential Kt inequality is
  derivable on either side. **O2 still applies.**
- **(O3)** Brandt's Lemma 2 needs an *infinite supply* of growing-
  length Kt-random prefixes generated by the run. The per-bit
  family supplies `J*(N) ≈ N − log₂ N` non-trivial fixed strings per
  N, all pre-determined. The "density" the proof requires is fresh
  Kt-random prefixes, not pre-determined strings. **O3 still
  applies.**
- **(O4)** Same as for `π_0`: uniform DTIME bound, not circuit.
  **O4 unaffected.**

The "minimal weakening of O1 admitting Brandt's TRAVERSE" the C3
spec asked about does **not** exist on `{π_J}`. Per-bit
decomposition is structurally orthogonal to Brandt's diagonalisation
skeleton. **Closure mode E** (equivalence with E5.8) at the
structural level.

## What is genuinely new

1. **The per-bit family is a new construction object.** Defined as
   `F_N = {s_J^(N) : J = 0..N-1}` it provides an informationally-
   complete decomposition of π on `[0, 2^N)`; the family had not
   been examined under bounded-Kt prior to S105.

2. **Bounded-Kt cut at `J*(N) ≈ N − log₂ N`.** A finite-N empirical
   fact about which bits are stack-VM-class compressible: only the
   trivially-zero bits are. This is a strict refinement of E1.3 at
   bounded-Kt resolution and quantifies precisely what the
   `brandt_mktp.py` simulator can resolve.

3. **Structural orthogonality of per-bit decomposition to Brandt's
   skeleton.** Confirmed wholesale (O1-O4 all persist), so per-bit is
   not a vehicle for circumventing E5.8.

## Successor challenge proposed

**C3.a — Arithmetic-primitive bounded-Kt VM.** Extend the 8-op stack
VM with primitives `LOG2`, `LI_APPROX`, `DIV_LOG`, `GEO_SUM` (the
R^{-1} kernel) and re-measure `Kt_b'(s_J^(N))`. Question: does the
bounded-Kt cut shift from J*(N) ≈ N − log₂ N toward E1.3's 0.5N
boundary?

- **YES** ⇒ R^{-1}-kernel-equipped VM resolves the smooth/oscillatory
  transition; a precise statement of "bit_J of π(x) is bounded-Kt-
  computable iff some specific arithmetic primitive set is in the VM."
- **NO** ⇒ a Kt-cut hierarchy `J^{(0)*} ≥ J^{(1)*} ≥ ... ≥ 0.5N`
  emerges, indexed by VM richness; the smooth/oscillatory transition
  needs primitives strictly stronger than the R^{-1} kernel to
  resolve.
