# B3 — Determinant-representation hunt for pi(x)

**Date:** 2026-04-26
**Verdict:** CLOSED — best k=2 candidate is a re-derived refinement of li(x).
**Mode:** E (equivalence to a known approximation), N (no genuinely new structure).

## What was tested

Hypothesis: there exists a polynomial-size matrix M(x) over a polylog-time
feature library such that det M(x) = pi(x).

Search procedure:

1. Build a 12-feature library:

   ```
   {one, x, log x, loglog x, sqrt x, x/log x, log^2 x, li(x),
    1/x, 1/log x, x*loglog x, x - log x}
   ```

2. Enumerate all 12^4 = 20,736 choices of 2x2 matrix
   M(x) = [[f_a, f_b], [f_c, f_d]] and score by RMSE of det M(x) - pi(x)
   on a 100-point grid x in [10, 5000].

3. Also try a 3-parameter affine correction
   det M(x) + alpha_0 + alpha_1 x + alpha_2 log x = pi(x)
   to absorb known leading-order shifts.

4. Extrapolate top-5 raw candidates to x in [6000, 10000].

5. Manually probe the winning candidate further at x = 10^6.

## Result

### Raw det hunt — top result (RMSE on training grid = 3.85)

```
M(x) = [[ 1       , log x   ],
        [ loglog x, li(x)   ]]
det M(x) = li(x) - log(x) * loglog(x)
```

Three additional top-tier ties (same RMSE) are co-factor permutations of
this same algebraic expression.

### Affine-corrected hunt (RMSE = 1.41)

The "best" candidate uses x/log x and loglog x and the affine corrector
absorbs a shift of -1.835 + (-0.12) x + 1.785 log x. That correction is
itself a polylog expression, so the full claim becomes a 5-feature linear
approximation. This is just **fitting pi(x) by linear combination of
{x/log x, loglog x, 1, x, log x}** — the standard PNT-corrected approximant.

Absolute error grows as ~sqrt(x); relative error stays around 0.1%. This
is **the same scaling as li(x) - pi(x)** — exactly the standard
prime-counting error term, which is RH-bounded by O(sqrt(x) log x).

## Why

The k=2 determinant of two-feature combinations spans the algebra
generated by the feature library under multiplication, addition, and
subtraction at degree 2. li(x) is itself in this library, so any
det formula has the structure

    det M(x) = (sum of products of features) =
    (li(x)) + (low-order polylog combination).

The chaotic, GUE-random part of pi(x) - li(x) is by construction
**not** in any small polynomial algebra over polylog features (it's
the sum of `O(sqrt(x))` independent zeta-zero contributions). The
empirical confirmation: the search recovered the best li-style
approximant available in the library, and its error is the standard
li-error.

## What would falsify this (if anyone did the work)

- A k=3 or k=4 determinant representation with sub-sqrt(x) error.
  We did not run k=3 because the search space is 12^9 = 5 x 10^9
  candidates — feasible only with smarter than brute enumeration.
- A non-polynomial feature library (e.g. including specific zeta-zero-
  derived expressions) at small k. But this just hides the zeros inside
  the features, not breaking any wall.

~1.5 seconds wall time for both raw and affine hunts at k=2.
