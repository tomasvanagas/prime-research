## Pre-stated falsification (before running)

Per `definition.md`, the experiment selects exactly one of:

- **F1 — collapse / DUPLICATE-PLUS.** `Kt_b(s_J^{(N)}) = INF = 61`
  uniformly over all (N, J). Bounded VM cannot distinguish bit
  positions; per-bit decomposition gives no new bounded-Kt structure;
  C3 reduces to E5.8 wholesale.
- **F2 — J-stratified, matches E1.3.** For every tested N: all
  `J < ⌈N/2⌉` saturate; at least one `J ≥ ⌈N/2⌉` strictly compresses.
  Bounded VM distinguishes hard / easy halves at the same boundary
  E1.3 identifies via Fourier weight.
- **F3 — anomalous.** Pattern is neither F1 nor F2.

The structural extension argument (does Brandt's TRAVERSE work on the
per-bit family?) is run independently and does not depend on the
empirical verdict.

## Verdict

**F2 holds in the meaningful saturation regime (N ≥ 4).**

The classifier function `classify_outcome` reported "F3 anomalous"
because the strict version of F2 demands ALL tested N satisfy the
condition, and N=3 has hard-J `Kt_b ∈ {15, 12}` (not saturated). But
the N=3 truth-table is only 8 bits long — *below* the bounded-VM
saturation threshold (the VM has L_MAX = 12-bit programs and can
generate any 8-bit string with ample budget). The strict 0/1 pattern
matters only when 2^N > L_MAX, i.e., N ≥ 4. **F2 holds for every
N ∈ {4, 5, 6, 7}.**

But there is a more interesting **sharpening of F2**: the bounded-Kt
cut is **NOT** at E1.3's 0.5N boundary. It is at

```
    J*(N)  :=  ⌈log₂( π(2^N - 1) + 1 )⌉.
```

Numerically:
- N = 4: π(15) = 6, J*(4) = ⌈log₂ 7⌉ = 3 (vs E1.3's 0.5·4 = 2)
- N = 5: π(31) = 11, J*(5) = ⌈log₂ 12⌉ = 4 (vs 2.5)
- N = 6: π(63) = 18, J*(6) = ⌈log₂ 19⌉ = 5 (vs 3)
- N = 7: π(127) = 31, J*(7) = ⌈log₂ 32⌉ = 5 (vs 3.5)

For every J ≥ J*(N), `π_J ≡ 0` on `[0, 2^N)` and the truth-table is
all zeros — bounded-Kt-trivial (Kt_b ≈ 5..8, generated by `RPT4`).

For every J < J*(N), including J's in E1.3's "easy zone"
(J ∈ [⌈0.5N⌉, J*(N)) — the bits whose Fourier weight is concentrated
at low degree and whose R-correlation is high), the bounded-Kt
simulator returns INF = 61 (saturated).

**Concrete examples of saturation in E1.3's easy zone:**
- N = 5, J = 3: 13 ones in 32 bits (mostly-zero pattern), Kt_b = 61.
- N = 6, J = 3: 34 ones (high R-correlation), Kt_b = 61.
- N = 6, J = 4: 11 ones (mostly-zero pattern), Kt_b = 61.
- N = 7, J = 4: 75 ones (high R-correlation), Kt_b = 61.

The bounded VM is BLIND to the smooth/oscillatory transition E1.3
identifies via Fourier weight. It only resolves the *trivially*-easy
boundary (J ≥ J*(N) where π_J ≡ 0). This is a **strict refinement**
of F2's pre-stated form — the J-stratification exists, but the cut
location is materially higher than E1.3's, by an additive gap that
grows roughly as `N - log₂ N - 0.5N` ≈ `0.5N - log₂ N`.

## Structural analysis (O1-O4 on the per-bit family)

The C3 spec asks: "find the minimal weakening of E5.8's O1 that still
admits Brandt's TRAVERSE technique." Working through the four
obstructions on the per-bit family `{π_J : J = 0, 1, ..., N-1}`:

**(O1) Hard string is fixed, not oracle-dependent.** Each `π_J` is a
fixed total Boolean function `ℕ → {0,1}`. Per-bit decomposition does
NOT relax O1: a parameterised function family is still a family of
fixed functions. There is no path from a "fast π_J-decider Π_J" to
the production of a Kt-random string of growing length, for any
single J or any combination across J.

**(O2) Self-referential Kt.** The Brandt contradiction needs the same
complexity measure on both sides of an inequality. `π_J` answers "is
bit J of π(x) set", not "is z complicated". No self-referential Kt
inequality can be derived from a π_J-decider, regardless of J.

**(O3) Density of hard witnesses.** Brandt's Lemma 2 needs an INFINITE
supply of growing-length Kt-random prefixes (Chaitin Ω). The per-bit
family supplies only `J*(N) ≤ ⌈log₂ π(2^N)⌉ ≈ N − log₂ N` non-trivial
strings per N — the rest are identically zero. As N → ∞ the count
J*(N) is unbounded but the strings are FIXED, not "fresh" prefixes
generated by oracle access. The "density" requirement is the existence
of NEW Kt-random strings of every length, on demand. The per-bit family
does not provide this — `s_J^{(N)}` is determined by (J, N), not by a
traversal-path-dependent run.

**(O4) Wrong complexity class.** Same as for `π_0`: Brandt's bound is
on uniform DTIME, not on circuits. Per-bit decomposition does not
change the complexity class of the bound.

**Conclusion.** All four obstructions O1, O2, O3, O4 still apply to
the per-bit family. The "minimal weakening of O1 that still admits
Brandt's TRAVERSE" the spec asked about does NOT exist within
`{π_J}`. Per-bit decomposition is **structurally orthogonal** to
Brandt's diagonalisation skeleton.

## Empirical content beyond E5.8 + E1.3

The construction *does* produce one quantitative new fact:

> **Empirical fact (S105).** Under the 3-bit-per-instruction stack VM
> with `L_MAX = 12`, `T_MAX = 4096` (the simulator from
> `brandt_mktp/`), the per-bit Kt-bounded function `Kt_b(s_J^{(N)})`
> exhibits a sharp threshold at
> `J* = ⌈log₂(π(2^N - 1) + 1)⌉ ≈ N − log₂ N`, with `Kt_b = INF` for
> `J < J*` and `Kt_b ∈ [5, 8]` (trivial zero-string) for `J ≥ J*`.
> The bounded VM is **blind** to E1.3's smooth/oscillatory transition
> at `0.5N`: bits in E1.3's "easy zone" but below `J*` saturate the
> bounded VM exactly like bits in E1.3's "hard zone".

This is a precise *negative* refinement of E1.3 at the bounded-Kt
level: the smooth/oscillatory information channel that distinguishes
top-half bits from bottom-half bits in the Fourier-spectrum sense is
invisible to a VM whose primitives are confined to stack manipulation
and constant emission. Detecting it would require arithmetic primitives
(integer-log, Li-approximation, geometric sum) — see successor
challenge below.

## Status

**BUILT, no polylog opening.** Closure at structural level is mode E
(equivalence) with E5.8: per-bit decomposition does not weaken
Brandt's obstructions. Empirical refinement of E1.3 at bounded-Kt
resolution: cut location at `J*(N) = ⌈log₂(π(2^N)+1)⌉`, materially
higher than E1.3's `0.5N`.

## Successor challenge (proposed in S105)

**C3.a — Arithmetic-primitive bounded-Kt VM.** The S105 finding raises
a precise sub-question: does the bounded-Kt cut location move from
`J*(N) ≈ N − log₂ N` toward E1.3's `0.5N` if we extend the bounded VM
with arithmetic primitives? Specifically, augment the 8-op stack VM
with:

| Bits | Mnemonic   | Effect                                              |
|------|------------|-----------------------------------------------------|
| 1000 | LOG2       | Replace TOS with ⌊log₂ TOS⌋                         |
| 1001 | LI_APPROX  | Replace TOS with ⌊TOS / log TOS⌋ (R^{-1} kernel)    |
| 1010 | DIV_LOG    | Pop two: push a / log b                             |
| 1011 | GEO_SUM    | Push 1 + a + a² + ... up to T_MAX                   |

Test whether `Kt_b'(s_J^{(N)})` (under the extended VM) drops below
INF for the entire E1.3 easy zone `J ∈ [⌈0.5N⌉, J*)`. If yes, the
bounded-Kt cut shifts from `J*` toward `0.5N` and the smooth/
oscillatory transition becomes bounded-Kt-visible — a **new edge**
about which programs are "natural" for `π(x)`. If no, the shift is
bounded above by some intermediate cut `J^**` and we obtain a new
*hierarchy* of bit-difficulty cuts indexed by VM richness. Cost: 1 session.
