## Angles tested in this session

### 1. Mayer transfer operator (Gauss-Kuzmin-Wirsing) ✅
Selberg zeta `Z(s) = det(1−L_s) det(1+L_s)`. Naive Galerkin discretization on
monomial basis of size N=6..18. **Result: zero zeros recovered** — likely
the wrong critical line (true zeros at `s = 1/4 + iγ/2`, not `1/2 + iγ`).
Even if corrected, the operator gives at most N zeros from an `O(N³)` matrix,
no compression. CLOSED.

### 2. P-recursive (holonomic) structure of pi(n) ✅
Test if `pi(n)` — or `delta(n) = pi(n) − li(n)` — satisfies a polynomial-coefficient
recurrence `Σ p_j(n) a_{n+j} = 0` of low order/degree. **Result: in-window fit
looks promising (74% integer recovery at best), but extrapolation rollout
blows up to 10²⁰+ ; one-step error `O(1)` matches the magnitude of the
fluctuations being "predicted" — recurrence learns `li(n)` and nothing about
primes.** CLOSED.

## Angles not tested in this session (proposed for future work)

### 3. Free probability / R-transform of zero contributions to delta(x)
Treat the contribution of zero ρ_k to `delta(x)` at logarithmic scale `log x`
as a free random variable. The R-transform composes additively under free
convolution. If the empirical distribution of `delta(x)/√x` over `x ∈ [N, 2N]`
matches a known free-convolution form (free Poisson, free Wigner), it suggests
an analytic shortcut for sums-over-zeros via R-transform inversion.
**Test:** compute moments `E[(delta(x)/√x)^k]` over windows, compare to
classical Marchenko-Pastur and free-Poisson moments.
**Risk:** likely just GUE behavior already documented.

### 4. Persistent homology of {primes ≤ N} in a clever embedding
Embed primes as points in `R^d` via `(n, n*φ mod 1)` (golden-ratio rotation),
or `(log p_k, log p_{k+1})`. Compute persistence diagrams. If the diagram has
multiple long-lived 1-cycles (or non-trivial higher Betti numbers), the
topological signature could compress prime-counting information. Topological
Data Analysis on integer sequences is largely unexplored.
**Test:** compute 0,1-dimensional persistence using `gudhi` or `ripser`,
check Wasserstein distance between empirical diagram and that of a uniform
random subset of equal density.
**Risk:** primes' fractional parts via `n*φ` already known to be uniformly
distributed (Weyl), so no topology. Might still be informative for other
embeddings.

### 5. Optimal transport between primes and a Beatty sequence
Compute the Wasserstein-1 plan between `{primes ≤ N}` and `{floor(n·c) : n ≤ M}`
for various irrational `c`. If the OT plan is structured (e.g., a polylog-time
computable bijection), we'd have an algorithmic reduction. This generalizes
the "primes look like a Beatty sequence" intuition.
**Test:** small-scale OT computation N=10⁴, look for piecewise-linear or
sparse plans.
**Risk:** OT plans for "noise vs structured" sequences usually have full
support; sparse plans require both sequences to be structured.

### 6. Heat-kernel evaluation on Connes' adelic class space
The Connes-Bost-Connes system has spectral data conjecturally related to
zeta zeros. The heat trace `Tr exp(-tH)` for the Hamiltonian H of the
KMS state at inverse temperature `β > 1` admits a closed form via the
Euler product. The question: can analytic continuation in t give the zero
sum without enumerating zeros?
**Test:** numerical evaluation of the BC heat trace at several t and β;
check if extrapolation to the critical point t→1+ recovers `delta(x)`.
**Risk:** literature suggests the BC heat kernel is essentially zeta itself,
so this is circular.

### 7. Vandermonde-style determinantal structure of the prime indicator matrix
Build the matrix `A[i,j] = i^j mod p_j` for the first N primes and exponent
range j ∈ [0, M]. The determinant `det A` is a Vandermonde-like quantity.
If `det A` (or its factorization mod small primes) has fast computability
that reveals primality in batched form, we have a counting shortcut.
**Test:** compute small instances, look for closed form / Schur-polynomial
expansion.
**Risk:** Vandermonde determinants are well-studied; novelty is low.

### 8. Subadditive ergodic theorem applied to log-prime gaps
Define `T_k = log(p_{k+1}) − log(p_k)`. The cumulative sum `S_n = Σ T_k`
satisfies `S_n ≈ log p_n`. Subadditive ergodic theorem says `S_n / n → λ`
a.s. for stationary subadditive processes. If `T_k` admits a "thermodynamic
formalism" structure (Gibbs measure, transfer operator), we could compute
S_n fast via partition function.
**Test:** estimate the topological pressure of T_k on log-scale; see if
cumulants match a Gibbs phase.
**Risk:** Requires assuming `T_k` is generated by an ergodic dynamical
system, which contradicts known prime-gap heterogeneity.

### 9. Plouffe-style "n-th digit" formula for pi(x)
BBP formulas compute the n-th hex digit of π (the constant) without prior
digits via a series whose terms each contribute to a specific digit position.
**Question:** does pi(x) (the function) have an analogous representation
`pi(x) = Σ a_k(x) / B^k` where `a_k(x)` is a closed-form `O(polylog x)`-time
expression and only the first few k's matter? Equivalent: BBP for the prime
counting function.
**Test:** symbolic search via PSLQ over plausible bases. (Existing
`identity_search_pslq.py` did similar but for constants, not for the function.)
**Risk:** the explicit-formula zero sum *is* the BBP-like representation, and
it's not sparse — each "digit" depends on all zeros.

### 10. Variational lower bound on pi(x) via convex optimization
Formulate computing pi(x) as: maximize a *concave* functional whose maximum
equals pi(x). If the functional admits a first-order structure (linear in pi
plus a small concave penalty), interior-point methods give polylog iterations.
**Test:** Lagrangian dual of "count primes ≤ x" via continuous relaxation
(e.g., LP with one variable per integer in [1, x]). The natural relaxation
is trivial; the question is whether a richer convex hull captures pi(x).
**Risk:** counting problems generally lack tight convex relaxations; #P
vs P barrier.

## 2025-2026 literature check (relevant new tools)

- **Guth-Maynard (2024)**: improved zero-density bound from Ingham's 3/5 to
  13/25 via large-value estimates for Dirichlet polynomials; gives PNT in
  shorter intervals (`x^{17/30+o(1)}` length). **Implication for this project:**
  better *estimates*, not better *exact* algorithms — does not change the
  `O(x^{1/2+ε})` analytic barrier on exact pi(x).
- **Valley Scanner Algorithm (2025, arXiv:2512.09960)**: real-to-complex
  parametrization of the Riemann-Siegel `Z(t)` lets one find zeros up to
  `t ~ 10^20` without Gram bracketing. **Implication:** faster zero tabulation
  helps the explicit-formula approach mildly, but does not avoid the need to
  *sum* `O(√x)` zeros.

Neither breakthrough opens a polylog path. Both improve constants and
intermediate estimates within the existing analytic framework.

## Meta-observation

After two fresh experiments on genuinely novel angles (Mayer operator,
P-recursive structure), both fail with the **same character**: smooth-part
fits look promising, but the prime fluctuations resist all algebraic
compression. This is consistent with the project's central finding (the
~50% smooth + ~50% irreducible-noise decomposition).

A *positive* result on any of items 3–10 would be major news. None of them
have a clear path to a positive answer; all are "high-variance" angles
worth testing only when the existing playbook is exhausted (which it is).
