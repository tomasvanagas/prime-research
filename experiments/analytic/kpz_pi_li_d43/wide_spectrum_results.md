# wide_spectrum — wide-range FFT + Hölder for D43

Wide-range diagnostic for the D43 KPZ experiment. Uses x ∈ [10⁴, 10⁷]
with KPZ step = ⌊(10⁷)^{1/3}⌋ = 215, n=46465 points, u = log(x)
span = 6.89, gamma resolution = 0.91. The wide u-span resolves the
first 12 non-trivial Riemann zeta zeros γ_k in the FFT.

**Key result**: D(x)'s top FFT peaks land at exactly γ_1 = 14.135
(peak/median 770000), γ_2 = 21.022 (760000), γ_3 = 25.011 (300000),
γ_5 = 32.935 (380000), confirming that D(x) is a deterministic
almost-periodic function generated by a sum of zeta-zero cosines
per the explicit formula `D(x) = -log(x) Σ_ρ x^{ρ-1}/ρ + lower order`.

Cramér model control D_C shows similar FFT bin pattern (random-walk
artifact at the sampling resolution); FFT alone is not a clean
chi_P-vs-Cramér discriminator, but DOES confirm D's deterministic
generation.

Wavelet Hölder regularity:
- chi_P raw α = 0.817, fit r² = 0.999 — smooth.
- chi_P detrended α = 0.218, fit r² = 0.224 — Hölder framework
  inapplicable (residual is oscillation-dominated, not Hölder).
- Cramér raw α = 0.996, fit r² = 0.994.
- Cramér detrended α = 0.432, fit r² = 0.592.

Detrended skew/exkurt have moving-avg-window artifacts (heavy tails);
not reliable for KPZ vs Gauss discrimination at this u-span.

`d43_kpz_pi_li_results.md` for the consolidated narrative.
